# PhoneDrop — завантаження

Обмін великими папками між телефоном Android і ПК з Windows — через Wi‑Fi, точку доступу телефона або USB‑модем, без інтернету й обмежень на розмір.

**[⬇ Завантажити останню версію](../../releases/latest)**

| Файл | Для чого |
|---|---|
| `PhoneDrop.exe` | програма для ПК (Windows 10/11) |
| `PhoneDrop.apk` | застосунок для Android 7.0+ |
| `PhoneDrop-instrukciya.txt` | інструкція українською |
| `PhoneDrop-firewall.bat` | якщо телефон не бачить ПК |

Програми самі перевіряють цей репозиторій і пропонують оновитися, коли виходить нова версія.
